
# LiveChat – Language Learning & Real-Time Chat Platform

LiveChat is a full-stack language learning and real-time communication platform that helps users connect with language learners, send and accept connection requests, and chat with connected users.

The platform allows users to discover language partners and practice languages through real-time conversations.

## ✨ Features

### 🔐 User Authentication

- User signup and login
- Secure authentication
- User account management

### 🌍 Language Learning

Users can select their language-learning preferences during onboarding and connect with other users for language practice.

### 🤝 Send Connection Requests

Users can discover other language learners and send connection requests to start building their network.

### 🔔 Connection Notifications

Users receive notifications when someone sends them a connection request.

Users can:

- Accept requests
- Reject requests
- View pending requests

### 👥 Friends / Connections

After accepting a connection request, users can view their connected language partners from the Friends section.

### 💬 Real-Time Chat

Users can start chatting **only after the connection request has been accepted**.

This allows users to practice their target language through real-time conversations.
